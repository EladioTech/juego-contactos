**Estado:** ESTABLE

## ¿Qué hay en esta versión?
Esta es una copia de seguridad exacta del proyecto en el momento en que funcionaba perfectamente el **Chat en Tiempo Real** entre dos personas.

### Lo que SÍ funciona:
- Sistema de Perfiles (Alias, Género y URL de Foto).
- Colores azul (chico) y rosa (chica).
- Creación de Salas con Código de 4 letras.
- Chat en tiempo real (los mensajes viajan instantáneamente de una ventana a otra).
- Modo "Rompehielos" (el bot lanza preguntas y los jugadores responden).
- Chat Libre (cuando se acaban las preguntas, se abre una caja de texto).
- Indicador visual de "¡Conectado!" en verde cuando el otro jugador entra.

### Lo que NO tiene (pendiente para la siguiente versión):
- Sistema de "Match" (Muro de perfiles).
- Verificación de tarjeta de discapacidad.
- Chat de voz para invidentes.

## ⚠️ IMPORTANTE
Si en el futuro rompes el código de la carpeta principal, **puedes recuperar esta carpeta y tendrás una versión 100% funcional del chat**. Solo tendrías que volver a conectar tus claves de Firebase en el archivo `main.js` si las has cambiado.
